# A complete fixed-class packing on T_13

Base checkpoint: R4-RESEARCH-0012. This is a lower bound for one specified color class, not for all proper colorings of T_13.

Use vertex id i=v(v-1)/2+u for the cell (v,u), where 1<=v<=12 and 0<=u<v. Fix color 2 on exactly the following ids:

    6, 9, 10, 13, 16, 21, 22, 25, 26, 27, 31, 32, 39, 41, 45, 46, 47, 53, 54, 59, 61, 70, 73, 76

The other vertices may be recolored arbitrarily with colors 0 and 1, subject to properness. The packing below, together with TWO_COLOR_REASSIGNMENT.md equation (4), gives R>=2041/100>20. Since R is integral, R>=21. The saved proper seed attains 21, so the minimum within this fixed-class problem is exactly 21. This makes no assertion that an arbitrary proper T_13 coloring has this class.

## How the object specifies a proof

Each edge row gives two vertices outside C and a third vertex in C. Those three cells form a directed corner. The edge is therefore present in G_C. The final column is its total packing load in units of 1/100.

Each tree row gives a weight in those same units, a directed corner wholly outside C, and a root followed by child:parent pairs. Every parent has appeared earlier in that row. Each pair is an edge from the edge table. Thus the row defines a connected tree containing the three displayed corner vertices. Any proper recoloring splits that corner, so at least one tree edge crosses its cut.

The weights total 2041 units, and every edge load in the table is at most 99 units, hence at most its capacity 100. Multiplying each tree inequality by its weight and summing yields 2041<=100 R. This argument is an explicit packing construction; no optimization status or exhaustive search is a proof premise.
