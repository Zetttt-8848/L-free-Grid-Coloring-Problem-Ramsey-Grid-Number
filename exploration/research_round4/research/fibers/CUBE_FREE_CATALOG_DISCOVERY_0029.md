# Cube-free catalog discovery scope

This one-pass profile reads the existing `window13.json` minimal-bad list and
computes only whether each positive difference fiber has pairwise distinct
positive start differences. It does not run SAT, inspect a coloring, or check
the catalog's earlier labels. Any listed all-fibers-Golomb support remains an
inherited bad label and requires a new symbolic obstruction before it can be
used mathematically.
