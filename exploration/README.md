# Historical mathematical exploration

These notes, probes, finite instances and earlier formalizations preserve the
research trail. They are not a collection of established theorems. Earlier
"current status" and bound claims are superseded by the current manuscript.
In particular F11(5), F12(7) and F13(17) are refuted by the current complete
coloring certificates. No historical weighted implication using these false
premises gives an unconditional Ramsey improvement. UNKNOWN is not UNSAT.

Notes and scripts retain their original filenames and relative layout. Local
machine paths have been replaced with LOCAL_RESEARCH_ROOT. Legacy scripts may
need path/dependency adaptation and were not rerun as part of this import.
Third-party papers, installed solvers, libraries, chat transcripts and personal
or submission materials are intentionally excluded. Source citations remain.
