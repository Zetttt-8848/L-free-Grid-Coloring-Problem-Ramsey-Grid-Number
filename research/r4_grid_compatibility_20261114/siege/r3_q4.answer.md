## 0. Notation and two elementary facts used throughout

Fix a proper ternary source (D, chi) and a shift d. Write:
- Y = F_d(D) and S = span Y = max Y - min Y;
- X_e = S_e(d) and s_e = |X_e|, so that sum_e s_e = |Y|;
- v_1 = v_1(S) = Q(S-1) + Q(S-2);
- c(S) = sqrt(v_1 S);
- ξ*(S) := K_F(S)/c(S) - 1.

**Fact Q-mon (PROVED).** Q is nondecreasing: Q(m) <= Q(m+1). An interval of m+1 consecutive integers lies inside one of m+2. Hence v_1(S) and c(S) are nondecreasing in S.

**Fact ξ (PROVED).** 0 <= ξ*(S) <= ξ(S) = 3.83 S^{-3/8} for S >= 34. This holds by Corollary 4.3 (K_F >= c) and Lemma 4.4 (K_F <= (1+ξ)c).

**Fact c/v_1 (PROVED, from Lemma 4.1).** For S >= 34 we have v_1 >= sqrt(S)/2. Hence c(S)/v_1 = sqrt(S/v_1) <= sqrt(2) S^{1/4}.

## 1. Step A: an FD-violator has three near-cap classes (Prop. 4.6(b), with ξ* in place of ξ)

**Lemma A (PROVED).** Let S >= 34, η >= 0, and suppose |Y| >= 3(1-η) c(S). Then every class satisfies s_e >= (1 - θ) c(S), where θ := 3η + 2ξ*(S) <= 3η + 2ξ(S).

*Proof.*
- Each X_{e'} is a binary source of span <= S with fibres r <= v_l <= v_1. This is (iv.0) and the per-fibre cap of C2, together with Q-mon.
- So s_{e'} <= K_F(S) = (1+ξ*)c by Corollary 4.3.
- Therefore s_e = |Y| - sum_{e' ≠ e} s_{e'} >= 3(1-η)c - 2(1+ξ*)c = (1 - 3η - 2ξ*)c. ∎

## 2. Step B: one lag that is saturated for two classes at once

**Which classes are needed.** For a color f, write {e, e'} = P \ {f}. By C3, U_f(l) = A_f ⊔ B_f, where:
- A_f = G_e^f is the f-colored Golomb class of F_l(X_e);
- B_f = G_{e'}^f is the f-colored Golomb class of F_l(X_{e'}).

The fibre of the third class X_f does not enter U_f(l) at all: by Lemma W(b), kappa(p,p) ≠ f for p in A^f. So **two classes suffice**: the two classes different from f, for one fixed f. In an FD-violator all three classes are near-cap (Lemma A), so we may fix f arbitrarily, say f = 0. The union bound is then over **two** classes. This is cheaper than over three: the condition is 2B < β', not 3B < β'.

**Lemma B (PROVED).** Let S >= 34 and θ = 3η + 2ξ*(S). Let λ be an integer with 1 <= λ <= S-1, put Λ = λ+1, and let β' > 0. Put

  B(S, λ, η) := 2θ + Λ/S + K_F(S)/(v_1 λ).

Assume that |Y| >= 3(1-η)c(S) and that

  **(H1)** 2 B(S, λ, η) < β'.

Then there is a lag l with 1 <= l <= λ such that r_{X_e}(l) >= (1-β') v_1 and r_{X_{e'}}(l) >= (1-β') v_1, for the two classes e, e' ≠ f.

*Proof.*
- **Bound on D̄.** By Lemma A, each of X_e and X_{e'} satisfies the hypotheses of Proposition 4.7: binary source, span <= S, S >= 34, r <= v_1, s >= (1-θ)c, 1 <= λ, Λ <= S. Here θ < 1, because (H1) gives 4θ < β' (and β' <= 1/4 in all uses below; in any case 2θ <= B < β'/2 < 1). Proposition 4.7(a) gives D̄_e(λ) <= 2θ + Λ/S + s_e/(v_1 λ), and s_e <= K_F(S). So D̄_e(λ) <= B, and likewise D̄_{e'}(λ) <= B.
- **Weights.** Use the weights w_l = Λ - l on 1 <= l <= λ. Every w_l >= 1 > 0, and the total weight is W_tot = λΛ/2.
- **Markov.** Let Bad_x = {l <= λ : r_{X_x}(l) < (1-β')v_1}. By Proposition 4.7(b), w(Bad_x) <= (D̄_x/β') W_tot <= (B/β') W_tot.
- **Union bound.** w(Bad_e ∪ Bad_{e'}) <= (2B/β') W_tot < W_tot by (H1). So some lag l in [1, λ], which has positive weight, lies outside both bad sets. ∎

## 3. Step C: both Golomb pieces at a saturated lag are (1-β)-near-maximal (l = 1 included)

**Lemma C' (PROVED).** Let X ⊆ Y be any class, 1 <= l <= S-1, and 0 < β' < β/2. Suppose r_X(l) >= (1-β')v_1, and

  **(H3)** Q(S-l) >= (1-β')/(β - 2β').

Then both Golomb classes of F_l(X) have size >= (1-β) Q(S-l).

*Proof.*
- **Upper bound on each class.** F_l(X) ⊆ {u in Y : u+l in Y} ⊆ [min Y, max Y - l], an interval of S-l+1 integers. Each Golomb class is a Sidon set there (iv.2), so it has size <= Q(S-l).
- **Lower bound on the smaller class.** The two classes partition F_l(X). So the smaller one has size g >= r_X(l) - Q(S-l) >= (1-β')v_1 - Q(S-l).
- **Claim: v_1 >= 2Q(S-l) - 1 for every l >= 1.**
  - If l >= 2: Q(S-2) >= Q(S-l) and Q(S-1) >= Q(S-2), by Q-mon. So v_1 >= 2Q(S-l).
  - If l = 1: Q(S-2) >= Q(S-1) - 1 by (Q-step). So v_1 >= 2Q(S-1) - 1.
- **Combine.** g >= (1-β')(2Q(S-l) - 1) - Q(S-l) = (1-2β')Q(S-l) - (1-β').
- This is >= (1-β)Q(S-l) iff (β - 2β')Q(S-l) >= 1-β', which is (H3). ∎

(For l >= 2 the term -(1-β') can be dropped. Only the case l = 1 needs the Q-step, and (H3) covers it uniformly.)

## 4. Step D: the TSD instance and the contradiction

**Lemma D (PROVED; this is C3/C4 "Link", re-verified).** Let l >= 1 and h = d+l, let f be a color, and let {e, e'} = P \ {f}. Define the coloring of the pairs p < q of U := U_f(l) by c(p,q) = 0 if kappa(p,q) = e', and c(p,q) = 1 if kappa(p,q) = e. Then (A, B, c) := (A_f, B_f, c) is a TSD instance of span m = S - l.

*Proof.*
- **c is well defined.** For p < q in U_f, kappa(p,q) lies in {e, e'} by Corollary U item 1.
- **Disjoint Sidon sets.** A_f ⊆ A^e and B_f ⊆ A^{e'}, and these are disjoint (C3). Both are Sidon by Corollary U item 4, or directly by (iv.2), since they are Golomb classes.
- **Interval.** U ⊆ F_l(X_e) ∪ F_l(X_{e'}) ⊆ [min Y, max Y - l], which has S-l+1 integers. So the span is m = S-l.
- **Constant pair colors.** By Corollary U item 3, kappa ≡ e' on A_f-pairs and kappa ≡ e on B_f-pairs. That is, c ≡ 0 on A-pairs and c ≡ 1 on B-pairs.
- **Properness.** Let u < v in U and g > 0 with u+g, v+g in U. Apply Lemma W(a) with p = u, x = g and y = v+g-u. Then 0 <= x < y, because u < v. The points p+x = u+g, p+y-x = v and p+y = v+g all lie in U ⊆ W. So kappa(u,u+g), kappa(u,v+g), kappa(v,v+g) are not all equal, hence neither are the three c-values (c is a bijective renaming). The case v = u+g is included. ∎

## 5. The theorems

**Theorem R' (parametrised; PROVED).** Assume NTSD(β, m_0) with β in (0, 1/2] and m_0 >= 1. Let S >= 34, η >= 0, β' in (0, β/2), and an integer λ in [1, S-1] satisfy:
- (H1) 2[6η + 4ξ*(S) + (λ+1)/S + K_F(S)/(v_1(S) λ)] < β';
- (H2) S - λ >= m_0;
- (H3) Q(S-λ) >= (1-β')/(β-2β').

Then every proper ternary source and every shift d with span F_d(D) = S satisfy |F_d(D)| < 3(1-η) c(S).

*Proof.* Suppose |Y| >= 3(1-η)c(S). Note that 2B(S,λ,η) is exactly the bracket in (H1), since 2θ = 6η + 4ξ*.
1. Fix f = 0. Lemma B gives a lag l in [1, λ] at which both classes e, e' ≠ f are saturated at level 1-β'.
2. Q(S-l) >= Q(S-λ) by Q-mon, so (H3) holds at S-l. Lemma C' then shows that all four Golomb classes of F_l(X_e) and F_l(X_{e'}) have size >= (1-β)Q(S-l). In particular |A_f|, |B_f| >= (1-β)Q(m) with m = S-l.
3. By Lemma D, (A_f, B_f, c) is a TSD instance of span m. Also m >= S-λ >= m_0 by (H2).
4. This contradicts NTSD(β, m_0). ∎

**Theorem R (explicit; PROVED).** For β in (0, 1/2] and m_0 >= 1, put

  η(β) = β/48,  S_0(β, m_0) = max( (1471/β)^{8/3}, (96/95) m_0 ).

Then NTSD(β, m_0) implies FD(η(β), S_0(β, m_0)). In fact the inequality is strict: |F_d(D)| < 3(1-β/48)c(S) whenever span F_d(D) = S >= S_0.

*Proof.* Let S >= S_0. Take β' = β/3, η = β/48 and λ = ⌊βS/48⌋, and verify the hypotheses of Theorem R', using ξ* <= ξ = 3.83 S^{-3/8} (Fact ξ) and K_F <= (1+ξ)c, so that K_F/v_1 <= (1+ξ)√2 S^{1/4} (Fact c/v_1).

**Preliminaries.**
- S >= (1471/β)^{8/3} >= (2942)^{8/3} > 1.7*10^9. So S >= 34, and βS >= 96, because (1471/β)^{8/3} >= 1471/β >= 96/β.
- Hence λ >= βS/48 - 1 >= βS/96 >= 1. Also λ <= βS/48 <= S/96 <= S-1.
- (1471/β)^{8/3} >= 1470.72^{8/3} β^{-8/3} gives 15.32 S^{-3/8} <= β/96, that is, 4ξ(S) <= β/96. Consequently ξ(S) <= β/384 <= 1/768.

**(H1).** We have 6η = β/8, 1/S <= β/384 (since S >= 384/β), and (λ+1)/S <= β/48 + 1/S. Also

  K_F/(v_1 λ) <= (1+1/768)·√2·S^{1/4}·96/(βS) <= 135.94 S^{-3/4}/β.

This is <= β/192 iff S^{3/4} >= 26101/β², i.e. S >= (26101/β²)^{4/3}. That is implied by S >= (1471/β)^{8/3} = (1471²/β²)^{4/3} = (2163841/β²)^{4/3}. Summing:

  6η + 4ξ* + (λ+1)/S + K_F/(v_1λ) <= β/8 + β/96 + β/48 + β/384 + β/192
  = (48 + 4 + 8 + 1 + 2)β/384 = 63β/384 < 64β/384 = β/6.

So the bracket in (H1), doubled, is < β/3 = β'. (H1) holds.

**(H2).** S - λ >= S(1 - β/48) >= (95/96)S >= m_0, since β <= 1/2 and S >= (96/95)m_0.

**(H3).** (1-β')/(β-2β') = (1-β/3)/(β/3) = 3/β - 1 < 3/β. Put m = S-λ >= (95/96)S. Then m >= (95/96)(1471/β)^{8/3} >= 72/β² >= 288 >= 32. Indeed (1471/β)^{8/3} = 1471^{8/3} β^{-2} β^{-2/3} >= 1471^{8/3} β^{-2}, far above 73β^{-2}. So by (Q-low), Q(m) > sqrt(m/8) >= sqrt(9/β²) = 3/β, and (H3) holds.

Theorem R' applies. ∎

**Remark (the constant 48; PROVED via Theorem R').** For any fixed η < β/24 there is an explicit S_0 for which NTSD(β, m_0) implies FD(η, S_0). Choose β' with 12η < β' < β/2. The quantities ξ(S), Λ/S with λ = ⌊εS⌋ and small ε, and K_F/(v_1λ) = O(S^{-3/4}/ε) all tend to 0. (H3) holds for large S, since Q(S-λ) -> ∞ by (Q-low). The limit β/24 is forced by the method: 2·2θ >= 12η must be < β' < β/2.

**Corollary R (PROVED, under NTSD(β, m_0)).** For every proper ternary source and every d with span F_d(D) = S >= S_0(β, m_0),

  sum_e |S_e(d)| = |F_d(D)| < 3(1-β/48) c(S) <= (1-β/48)·3K_F(S).

*Proof.* Theorem R, then c <= K_F (Corollary 4.3). This is Theorem 4.5(a) with δ = η. ∎

Equivalently, this is the per-shift (D-a) inequality with δ = β/48, against the sum of the three separate certified Fejér caps K_F(S).

## 6. Consumer remark (IMPLICATION ONLY; NTSD is a hypothesis)

Let chi be a proper four-coloring of [0,n)^2. Fix a color c and a shift d.
- **The diagonal class as a ternary source.** D_c with chi restricted to V(D_c), and the three colors other than c relabelled bijectively as {0,1,2}, is a proper ternary source. The cells of V(D_c) avoid c (Background), and relabelling preserves properness.
- **Span.** F_d(D_c) ⊆ [0, n-1-d], so S_c := span F_d(D_c) <= n-1-d.
- **Large span.** If S_c >= S_0, Corollary R and Q-mon give |F_d(D_c)| < 3(1-η)c(S_c) <= 3(1-η)c(n-1-d).
- **Small span.** If S_c < S_0, then |F_d(D_c)| <= S_c + 1 <= S_0.

Hence, under NTSD(β, m_0), with η = β/48:

  X_d = sum_c |F_d(D_c)| <= 3(1-η) sum_{c : S_c >= S_0} c(S_c) + S_0·#{c : S_c < S_0} <= 12(1-η) c(n-1-d) + 4 S_0.

2. **Different cap.** The comparison quantity is 12c(n-1-d), not the consumer's U_d = sum_{j=0}^{11} K(n-d-j-1), which uses the rank-inequality cap K and staggering. The heuristic figures K ≈ 4.58*10^5 and c ≈ 4.548*10^5 suggest that c is in fact smaller than K, which would only help. This is UNVERIFIED.

## 7. The weakest hypothesis the proof uses

The proof of Theorem R' at a given span S uses NTSD only through **one instance** produced in Step D. So it suffices to assume the following statement NTSD*(β, β', S, λ). It is strictly weaker than NTSD(β, m_0) restricted to spans m in [S-λ, S-1].

**NTSD*(β, β', S, λ).** There is no proper ternary source (D, chi) with a shift d, span F_d(D) = S, a lag l in [1, λ], and colors {e, e', f} = P, such that:
- (i) r_{S_e(d)}(l) >= (1-β')v_1(S) and r_{S_{e'}(d)}(l) >= (1-β')v_1(S);
- (ii) consequently (Lemma C'), the TSD instance (A_f, B_f, kappa) of Lemma D has both pieces of size >= (1-2β')Q(S-l) - (1-β');
- (iii) the coloring is the restriction kappa of the ternary source.

The instance also carries the full ambient structure of C3: the Lemma W constraints on all of W, including the complementary Golomb classes G_e^{e'} and G_{e'}^{e}, of size >= (1-2β')Q(m) - 1, which sit with A_f and B_f inside the saturated fibres.

**Coarser sufficient forms**, in decreasing strength (each implies the next):
1. NTSD(β, m_0).
2. NTSD for spans m in [(1-ε)S, S-1] with ε = λ/S only (ε = β/48 in Theorem R).
3. NTSD for those spans, restricted to instances whose pieces have size >= (1-2β')Q(m) - (1-β'). This is the threshold actually reached: with β' near β/2 it is about (1-β)Q(m). It is also implied by "size >= Q(m) - β'v_1" up to the l = 1 rounding.
4. Additionally restricted to instances whose coloring is a restriction kappa of a ternary source, as in NTSD*.

Moreover, by Section 2, only ONE pair (e, e') is needed (any f), so the hypothesis is never applied to the third class.
