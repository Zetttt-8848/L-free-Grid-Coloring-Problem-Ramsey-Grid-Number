# Commit query 3: the aligned half of NTSD, translate pairs via Theorem T and gadgets

**Route.** For translate pairs B = A + t (A Sidon with no difference in [1, 2t], so first-generation forcing gives no contradiction by Proposition O), Theorem T (item C7) reduces TSD-colorability exactly to the finite order system (T1)-(T4) on the starts of A-pairs. Prove that a near-maximal A always makes this system unsatisfiable, by showing that near-maximality forces one unsatisfiable configuration: the gadget G1 of C7, or another gadget extracted from (T1)-(T4). Then extend from exact translates to pairs where a large part of B is a translate of a part of A. Write the full rigorous proof.

**What is wanted, in order of preference.**
1. **Translate theorem.** Explicit η_t > 0 and N_t (or one pair η, N_0 uniform in t ≤ t_0, or a form valid for all t ≤ c·sqrt(N)) such that for every Sidon set A ⊆ [0, N] with N ≥ N_t, |A| ≥ (1−η_t)Q(N), and no difference in [1, 2t], the pair (A, A + t) has no TSD coloring. A complete proof. Only the existence of ONE unsatisfiable configuration is needed (not Θ(N) copies).
2. **Partial translates.** The same conclusion for disjoint Sidon sets A, B with |A|, |B| ≥ (1−η)Q(N) and |(A + t) ∩ B| ≥ (1−γ)|A| for some t (explicit γ), or for the weakest "aligned" hypothesis you can handle. State it precisely; it is meant to complement a separate argument that finds C-collisions in non-aligned pairs.
3. If (1) is false, an explicit near-maximal A with (A, A+t) TSD-colorable, with the coloring, checkable L by L. Report the sizes against Q(N).

**Suggested steps.**
- The Counting Lemma G1(t) in EXISTENCE form: some A-pair (x, y) has both x + y − t and x + y + t in the inner sumset {a + a' : a, a' ∈ A ∩ (x, y)}. For near-maximal A, the sumset A + A has about |A|^2/2 elements and each element has one representation. Show by counting (or by a pigeonhole on sums near the center of [0, 2N]) that three sums s − t, s, s + t with nested representations must occur. Note that s = x + y itself must be the sum of the OUTER pair, and the two other sums must use points strictly inside (x, y).
- If the G1 count cannot be forced, use (T1)-(T4) directly: (T1) and (T2) fix X_δ and Y_δ by order bits σ(δ) on T = {δ : δ, δ + t ∈ Δ}; find two different forcing paths to one variable with opposite values. By Lemma S (C6), Δ(A) contains almost all small differences, so T contains almost all small δ.
- Computer evidence in C9: for t = 1 and near-maximal trimmed Bose sets (|A|/q ≥ 0.85, q = 17, 19, 23), G1 copies exist and the instance is not colorable; two non-colorable instances with t = 3 and |A|/q ≈ 0.7 contained no G1, so another gadget exists in general.

**Pitfalls.** The statement must hold for every near-maximal Sidon set, including algebraic ones (Bose, Singer, Erdős–Turán), not only random-like ones. Pair correlations (energy, Lemma E type bounds) do not control the three-point sumset correlation that G1 needs; say what extra input you use. Mark any classical result you cite as cited.

### C1. Lemma 0 (parametrisation of all L's in V(D)) — PROVED, quoted verbatim
For integers u and 1 ≤ d < h, let L(u,d,h) be the triple

- horizontal arm end (u+d, u),
- corner (u+h, u),
- vertical arm end (u+h, u+h−d),

with arm length h−d.

(a) L(u,d,h) is a directed L: take x = u+d, y = u, t = h−d > 0.

(b) L(u,d,h) ⊆ V(D) iff u, u+d, u+h−d, u+h all lie in D. The three cells lie in V(D) iff the pairs {u, u+d}, {u, u+h}, {u+h−d, u+h} lie in D, because the order conditions u < u+d, u < u+h, u+h−d < u+h hold automatically.

(c) Every directed L inside V(D) equals L(u,d,h) for exactly one triple. Given (x,y),(x+t,y),(x+t,y+t) in V(D), we have x > y. Put u = y, d = x−y ≥ 1, h = d+t > d. Conversely, L(u,d,h) determines y = u, x = u+d, t = h−d.

Coincidences such as d = h−d are harmless: condition (b) is a membership condition on the set {u, u+d, u+h−d, u+h}. The three cells are always distinct.

**Colors of the three cells.** χ(u+d,u) = e iff u ∈ S_e(d). The vertical arm end is (w+d, w) with w = u+h−d, so χ(u+h,u+h−d) = e iff u+h−d ∈ S_e(d). χ(u+h,u) = e iff u ∈ S_e(h). Hence:

> **(★)** L(u,d,h) lies in V(D) and is monochromatic of color e iff u ∈ F_{h−d}(S_e(d)) ∩ S_e(h).

Membership in S_e(·) already contains the D-membership conditions of (b). Also, m_{e,h}(u) is the number of L's with corner (u+h,u) whose two arm cells both have color e.


### C2. Inside one class: the shifted binary source, the Golomb split, the per-fibre cap — PROVED, quoted verbatim
(Here Q(m) is the largest size of a Sidon set inside m+1 consecutive integers; a Sidon set has no nontrivial solution of a+b=a'+b', repeated summands included, so 3-term progressions are excluded. S = span F_d(D), v_l = Q(S-l)+Q(S-l-1).)

Fix X = S_e(d), a lag l ≥ 1, and h = d+l. For a < b in X put ψ(a,b) = χ(b+d, a). This cell lies in V(D), because a, b+d ∈ D and b+d > a.

**(iv.0) The shifted source is a binary source avoiding e. PROVED.**
- For a < b in X, the L L(a, d, d+(b−a)) has horizontal arm end (a+d,a), of color e because a ∈ X. Its vertical arm end is (b+d,b), of color e because b ∈ X. Its corner is (b+d,a). So ψ(a,b) ≠ e, and ψ takes values in {e', e''}.
- ψ is proper on V(X) under the identification (b,a) ↦ (b+d,a). An L (x,y),(x+t,y),(x+t,y+t) in V(X) maps to (x+d,y),(x+t+d,y),(x+t+d,y+t). That is a directed L of V(D): it is the horizontal translate by d, and x+d > y, x+t+d > y+t.
- So X is a binary source. The same holds for every subset of X (heredity), and span X ≤ span F_d(D).

**(iv.1) F_l(X) ⊆ R_e(h).** F_l(X) = F_{h−d}(S_e(d)) is the d-term of R_e(h). ∎

**Color identification.** For u ∈ F_l(X) we have u, u+l ∈ X, so χ(u+h, u) = ψ(u, u+l) ∈ {e', e''}. For f ∈ {e',e''} put G_f = {u ∈ F_l(X) : χ(u+h,u) = f} = F_l(X) ∩ S_f(h). The two Golomb classes G_{e'} and G_{e''} partition F_l(X).

**(iv.2) Golomb split. PROVED.** Each G_f is a Sidon set. Equivalently, there are no u_1 and r, s > 0 with u_1, u_1+s, u_1+r, u_1+r+s ∈ G_f; the case r = s, a 3-term progression, is included.

*Proof.* Suppose such points exist. Let g be the color of {e',e''} other than f. The points u_1+l, u_1+s+l, u_1+r+l, u_1+r+s+l lie in X, because the four points lie in F_l(X). Consider four L's.
- **L1 = L(u_1, h, h+r).** Its cells are (u_1+h, u_1), of color f; the corner (u_1+h+r, u_1); and (u_1+h+r, u_1+r), of color f because u_1+r ∈ G_f. So the corner is not f. The corner is ψ(u_1, u_1+l+r), so it is not e by (iv.0). Hence it is g.
- **L2 = L(u_1+s, h, h+r).** The same argument with u_1+s, u_1+s+r ∈ G_f gives χ(u_1+s+h+r, u_1+s) = g.
- **L3 = L(u_1, h+r, h+r+s).** Its cells are (u_1+h+r, u_1), of color g by L1; the corner (u_1+h+r+s, u_1); and (u_1+h+r+s, u_1+s), of color g by L2. So the corner is not g. It is ψ(u_1, u_1+l+r+s), so it is not e. Hence it is f.
- **L4 = L(u_1, h, h+r+s).** Its cells are (u_1+h, u_1), of color f; the corner (u_1+h+r+s, u_1), of color f by L3; and (u_1+h+r+s, u_1+r+s), of color f because u_1+r+s ∈ G_f. This L is monochromatic, a contradiction.

All four L's lie in V(D) by Lemma 0(b), since all the required points lie in D. ∎

**Per-fibre cap (PROVED).** Let X ⊆ F_d(D) be any class and S = span F_d(D). Then F_l(X) lies in an interval of S−l+1 integers and is the union of two disjoint Sidon sets. They cannot both contain the left endpoint, so one of them lies in S−l consecutive integers. Hence r_X(l) ≤ Q(S−l) + Q(S−l−1) = v_l ≤ v_1.

### C3. The lag-l start set and its three binary layers U_f — PROVED, quoted verbatim from an earlier answer

Fix a proper ternary source (D, chi), a shift d >= 1 and a lag l >= 1, and put h = d+l.

**Definitions.**
- `X_e = S_e(d)` and `A^e = F_l(X_e)`. The sets A^0, A^1, A^2 are pairwise disjoint, because the X_e are.
- `W = A^0 ∪ A^1 ∪ A^2`, and `cls(p) = e` for p in A^e.
- For p <= q in W, `kappa(p,q) := chi(q+h, p)`.

**This is a cell of V(D).** We have p in D. Also q+l is in X_e, which lies in F_d(D), so q+h = (q+l)+d is in D. Finally q+h > p.

**Lemma W.**

(a) **Properness.** Let p in W and 0 <= x < y be such that p+x, p+y-x and p+y all lie in W. Then the three values kappa(p,p+x), kappa(p,p+y), kappa(p+y-x,p+y) are not all equal.

(b) **In-class constraints.** If p <= q both lie in A^e, then kappa(p,q) != e. In particular the diagonal value kappa(p,p) = chi(p+h,p) is != cls(p).

*Proof of (a).* Consider L(u,d1,h1) of Lemma 0 with u = p, d1 = h+x, h1 = h+y. Then 1 <= d1 < h1. Its three cells are:
- the horizontal arm end (p+h+x, p) = kappa(p,p+x);
- the corner (p+h+y, p) = kappa(p,p+y);
- the vertical arm end (p+h+y, p+y-x) = kappa(p+y-x, p+y).

By Lemma 0(b), it lies in V(D) iff p, p+h+x, p+y-x and p+h+y are all in D. This holds:
- p and p+y-x lie in W, which is contained in D;
- p+x lies in W, so p+x+h is in D by the remark above;
- likewise p+y lies in W, so p+y+h is in D.

Properness of chi gives the claim. ∎

*Proof of (b).* Let p <= q be in A^e. Then p and q+l lie in X_e, and p < q+l. By (iv.0), psi(p,q+l) = chi(q+l+d, p) = kappa(p,q) is != e. ∎

**Diagonal classes.** Put `U_f = {p in W : kappa(p,p) = f}`. By (b), U_f is contained in the union of the A^e with e != f. Writing `{e,e'} = P \ {f}`, U_f is the disjoint union of
- `A_f := A^e ∩ U_f = G_e^f` and
- `B_f := A^{e'} ∩ U_f = G_{e'}^f`.

For every lag l, the six pieces partition W, and
`sum_e r_{S_e(d)}(l) = |W| = |U_0| + |U_1| + |U_2|`.

**Corollary U (each U_f is a binary source with constant internal colors).** Write c(p,q) = kappa(p,q) for p < q in U_f.

1. c takes values in P \ {f} = {e, e'}.
2. For all p1 < p2 <= p3 < p4 in U_f with p1+p4 = p2+p3, the two triples
   `T1 = {c(p1,p2), c(p1,p4), c(p3,p4)}` and `T2 = {c(p1,p3), c(p1,p4), c(p2,p4)}`
   are both non-monochromatic. When p2 = p3 they coincide.
   Equivalently, by Lemma 0 applied to U_f, the coloring (q,p) -> c(p,q) of V(U_f) is proper. So U_f is a binary source.
3. c is identically e' on pairs inside A_f, and identically e on pairs inside B_f.
4. Consequently A_f and B_f are Sidon sets, including 3-term progressions. This is the Golomb split (iv.2).

*Proof.*
- **Item 1.** Apply Lemma W(a) with x = 0 and y = q-p. This gives kappa(p,p), kappa(p,q), kappa(q,q) not all equal. The first and last both equal f, so c(p,q) != f.
- **Item 2.** Apply Lemma W(a) at p = p1. For T1 take x = p2-p1 and y = p4-p1; then p1+y-x = p3. For T2 take x = p3-p1 and the same y; then p1+y-x = p2. All four points lie in W.
- **Item 3.** For p < q in A_f, c(p,q) != f by item 1, and != e by Lemma W(b). So c(p,q) = e'. The same argument gives the value e on B_f.
- **Item 4.** Any additive quadruple or 3-AP inside A_f would make T1 monochromatic of color e'. ∎

**Special cases.**
- Lemma F is item 1 together with item 3.
- The AABA and ABAA forcings of the earlier answers are item 2 applied to a single mixed quadruple, given item 3. See Section 2.

**Remark: one level down.** (W, kappa) is the exact analogue of the square, one level down:
- the "diagonal" kappa(p,p) is 3-colored;
- each diagonal class has a strict source avoiding its own diagonal color, hence 2-colored;
- the class labels cls add the constraints of Lemma W(b).

### C6. Small-difference saturation of near-maximal Sidon sets — PROVED, quoted verbatim from an earlier answer
## 4. Small-difference saturation (PROVED; the input for any counting lemma)

**Lemma S.** Let A ⊆ [0,N] be Sidon with |A| = k, and let 1 <= T <= N. Then

    sum_{g=1}^{T-1} (T-g) · 1[g ∉ Δ(A)]  <=  T(T-1)/2 - T^2 k^2 / (2(N+T)) + Tk/2.

If k >= (1-eta) sqrt(N), then the right-hand side, divided by the maximal weight T(T-1)/2, is at most 1 - (1-eta)^2 N/(N+T) · T/(T-1) + k/(T-1). This is at most 2eta + T/N + 2(sqrt(N)+1)/(T-1) for T >= 2.

*Proof.* Put a(x) = |A ∩ [x, x+T)| for the N+T integers x in [-(T-1), N]. Then sum_x a(x) = Tk. Also sum_x a(x)(a(x)-1) = sum_{a≠a'} (T - |a-a'|)_+ = 2 sum_{g=1}^{T-1} (T-g) 1[g in Δ], because A is Sidon. By Cauchy-Schwarz, sum a^2 >= (Tk)^2/(N+T). Hence

    2 sum_{g<T} (T-g) 1[g in Δ] >= T^2k^2/(N+T) - Tk.

Subtract this from the total weight 2 sum_{g<T}(T-g) = T(T-1). For the second form:
- The ratio equals 1 - T k^2/((N+T)(T-1)) + k/(T-1).
- Use k^2 >= (1-eta)^2 N >= (1-2eta) N, N/(N+T) >= 1 - T/N, and T/(T-1) >= 1.
- Use k <= N^{1/2} + N^{1/4} + 1 <= 2(sqrt(N)+1). This is the classical Erdős–Turán/Lindström bound, cited from memory.

∎

**Corollary S2.** Take a TSD instance in an interval of span m with |A| + |B| >= (1-eta)(Q(m)+Q(m-1)). Then each of |A|, |B| is >= (1-2eta) Q(m) - 2 >= (1-3eta) sqrt(m) for m large. This is because each is at most Q(m). Hence, for sqrt(m) << T << m, all but a fraction O(eta + T/m + sqrt(m)/T) of the weight sum_{g<T}(T-g) lies on differences g common to A and B.
- At each such g, Lemma C gives the no-collision constraint.
- Section 3 shows that the dangerous case where A-starts and B-starts are aligned (translates) is handled by G1 instead.

This is the precise sense in which a proof of TSD has to be a **dichotomy**:
- either A and B are not translate-correlated, and then Lemma C collisions should occur at a positive rate;
- or they are translate-correlated, and then G1-type gadgets should occur at a positive rate.

Neither half is proved. The dichotomy itself is a heuristic organisation, not a theorem.

### C7. The translate model reduced exactly (Theorem T) and the gadget G1 — PROVED, quoted verbatim from an earlier answer
(In this text a TSD coloring of U = A ∪ B is a proper 2-coloring c of the pairs x<y of U, i.e. of V(U) in pair language, with c = 0 on A-pairs and c = 1 on B-pairs; this is exactly the structure of Corollary U item 2-3, with colors renamed.)
## 2. The translate model, reduced exactly (PROVED)

This section settles the question left OPEN at the end of Proposition O: is the whole binary system on A ∪ (A+t) satisfiable? The answer is that it reduces to a finite list of order conditions on the pair starts of A. Section 3 extracts a configuration of A that makes it unsatisfiable.

**Setting.** Let t >= 1. Let A be a finite Sidon set (all positive differences distinct, 3-APs excluded) with no positive difference in [1, 2t]. Put B = A + t and U = A ∪ B. Let Δ be the set of positive differences of A. For δ in Δ let α_δ be the unique a in A with a + δ in A. Write the colors as 0 (= α, the color on A-pairs) and 1 (= β, the color on B-pairs). A **TSD coloring** is a map c on pairs x < y of U with c = 0 on A-pairs and c = 1 on B-pairs. It must be proper: for all u < v in U and g > 0 with u+g, v+g in U, the values c(u,u+g), c(v,v+g), c(u,v+g) are not all equal. (These are exactly the L's of V(U), by Lemma 0 in pair language.)

**Facts used repeatedly (from "no difference in [1,2t]").**
- A ∩ B = ∅, since t ∉ Δ.
- If a1, a2 in A and a1 ≠ a2, then |a1 - a2| > 2t.
- In particular α_g ≠ α_{g±t}. Also α_{g-t} ≠ α_{g+t}, since otherwise A would contain two points at distance 2t. Any two distinct starts differ by more than 2t. So comparisons such as "α_{g-t} < α_g + t" are equivalent to "α_{g-t} < α_g".

**The mixed cells.** A mixed pair (x < y, one point in A and one in B) is one of the following.
- An **AB pair** (a1, a2 + t), with a1 < a2 + t. If a1 > a2, then a1 - a2 would be a difference in [1, t-1]. So a1 <= a2.
  - If a1 = a2, write φ(a) := c(a, a+t).
  - If a1 < a2, then δ = a2 - a1 is in Δ, a1 = α_δ, and we write X_δ := c(α_δ, α_δ + δ + t).
- A **BA pair** (a1 + t, a2), with a1 + t < a2. Then δ = a2 - a1 > t is in Δ, and we write Y_δ := c(α_δ + t, α_δ + δ).

So the free variables are φ(a) (a in A), X_δ and Y_δ (δ in Δ). Their number is |A| + 2|Δ| = |A|^2 = |A||B|.

**Pairs of U of a given length g.**
- Length g = t: only the |A| pairs (a, a+t). The candidates A_t and B_t need t in Δ, and BA_t needs 2t in Δ; neither holds.
- Length g ≠ t: at most four pairs.
  - A_g = (α_g, α_g+g), color 0, if g in Δ.
  - B_g = (α_g+t, α_g+t+g), color 1, if g in Δ.
  - AB_g = (α_{g-t}, α_{g-t}+g), color X_{g-t}, if g-t in Δ.
  - BA_g = (α_{g+t}+t, α_{g+t}+t+g), color Y_{g+t}, if g+t in Δ.

  Uniqueness holds because each of these is determined by an A-pair of a prescribed difference, and A is Sidon.

Every L of V(U) consists of two pairs of the same length g and their spanning pair. So the constraint system is the list of all pairs of pairs below.

**Order bit.** For δ with δ, δ+t both in Δ (write δ in T), put σ(δ) := 1 if α_δ < α_{δ+t}, and σ(δ) := 0 otherwise. For δ in T define the **outer span** D(δ) := max(α_δ + δ, α_{δ+t} + δ + t) - min(α_δ, α_{δ+t}). Concretely, D = α_{δ+t} + δ + t - α_δ if σ = 1, and D = α_δ + δ - α_{δ+t} if σ = 0. In both cases D(δ) is in Δ, and its start α_{D(δ)} is min(α_δ, α_{δ+t}).

**Theorem T.** A TSD coloring of U = A ∪ (A+t) exists iff there are values φ: A -> {0,1}, X, Y: Δ -> {0,1} satisfying the following conditions.

- (T1) For each δ in T: X_δ = σ(δ) and X_{D(δ)} = 1 - σ(δ).
- (T2) For each g in T: Y_{g+t} = σ(g) and Y_{D(g)} = 1 - σ(g).
- (T3) For each g > t with g-t and g+t in Δ:
  - if α_{g-t} < α_{g+t}, then not (X_{g-t} = 0 and Y_{g+t} = 0);
  - otherwise, not (X_{g-t} = 1 and Y_{g+t} = 1).
- (T4) For each δ in Δ: φ(α_δ), φ(α_δ+δ) and X_δ are not all equal.

*Proof.* We go through all pairs of same-length pairs.

**Length t.** For a1 < a2 in A, the pairs (a1,a1+t) and (a2,a2+t) span (a1, a2+t). This is the cell X_{a2-a1}. Running over all A-pairs gives (T4).

**Length g ≠ t.**

- **(A_g, B_g).** The colors are 0 and 1, so this pair imposes no constraint.

- **(A_g, AB_g)** (g and g-t in Δ; put δ = g-t).
  - If α_δ < α_g: the spanning pair (α_δ, α_g+g) has both ends in A, so its color is 0. This forces X_δ = 1.
  - If α_g < α_δ: the spanning pair (α_g, α_δ+g) = (α_g, (α_δ+δ)+t) is an AB pair. Its A-difference is α_δ+δ-α_g. Its color is X_{α_δ+δ-α_g}, and the constraint is that 0, X_δ, X_{α_δ+δ-α_g} are not all equal.

- **(B_g, AB_g).**
  - If α_δ < α_g, then α_δ < α_g + t. The spanning pair (α_δ, α_g+g+t) is the AB pair X_{α_g+g-α_δ}, and the constraint is that 1, X_δ and this cell are not all equal.
  - If α_g < α_δ, then α_g + t < α_δ. The spanning pair (α_g+t, α_δ+g) has both ends in B, so its color is 1. This forces X_δ = 0.

  Combining the two cases:
  - When α_δ < α_g = α_{δ+t}, i.e. σ(δ) = 1: X_δ = 1 and X_{α_{δ+t}+δ+t-α_δ} = 0.
  - When σ(δ) = 0: X_δ = 0 and X_{α_δ+δ-α_{δ+t}} = 1.

  The indices are D(δ). This is exactly (T1).

- **(A_g, BA_g)** (g and g+t in Δ).
  - If α_g < α_{g+t}: the spanning pair (α_g, α_{g+t}+t+g) is an AA pair, so its color is 0. This forces Y_{g+t} = 1.
  - If α_{g+t} < α_g: then α_{g+t} + t < α_g. The spanning pair (α_{g+t}+t, α_g+g) is the BA cell Y_{α_g+g-α_{g+t}}, and the constraint is that Y_{g+t}, 0 and this cell are not all equal.

- **(B_g, BA_g).**
  - If α_g < α_{g+t}: the spanning pair (α_g+t, α_{g+t}+g+t) is the BA cell Y_{α_{g+t}+g+t-α_g}, and the constraint is that 1, Y_{g+t} and this cell are not all equal.
  - If α_{g+t} < α_g: the spanning pair (α_{g+t}+t, α_g+g+t) is a BB pair, so its color is 1. This forces Y_{g+t} = 0.

  Combining the two cases gives Y_{g+t} = σ(g) and Y_{D(g)} = 1 - σ(g). This is (T2).

- **(AB_g, BA_g)** (g-t and g+t in Δ).
  - If α_{g-t} < α_{g+t}, the spanning pair (α_{g-t}, α_{g+t}+g+t) is an AA pair, so its color is 0.
  - Otherwise α_{g+t} + t < α_{g-t}, and the spanning pair (α_{g+t}+t, α_{g-t}+g) is a BB pair, so its color is 1.

  This is (T3).

No other pairs of equal-length pairs exist. Each identification of a spanning pair as a named variable uses the uniqueness of α. ∎

**Reading of Theorem T.** In the translate model every X_δ with δ in T, and every Y_δ with δ - t in T, is forced to an order bit of A. The remaining conditions say that these forced values never clash. The system is a finite 2-SAT/NAE system determined by the order of the starts of A-pairs at differences δ and δ ± t. This order is exactly the "cross" information that Fourier magnitudes of A cannot see.

## 3. Gadget G1: an unsatisfiable configuration (PROVED)

**Definition (G1 in A, step t).** Points x < y in A, together with y1, y2, z1, z2 in A ∩ (x, y), such that

    y1 + y2 = x + y - t,     z1 + z2 = x + y + t.

**Proposition G1.** Let A be a Sidon set with no positive difference in [1, 2t]. If A contains a G1 configuration, then U = A ∪ (A+t) has no TSD coloring.

*Direct proof from the L's of V(U).* This proof does not use Theorem T. Let c be a TSD coloring.

Part 1. Put g = y - y2. Then g = y1 + t - x, because y1 + y2 = x + y - t. The pairs of length g that we use are:
- (x, y1+t): an AB pair, with color X;
- (y2, y): an AA pair, with color 0;
- (y2+t, y+t): a BB pair, with color 1.

We use two L's.
- The L with u = x < v = y2: here u + g = y1 + t and v + g = y. Its cells have colors X, 0, and c(x, y) = 0. So X = 1.
- The L with u = x < v = y2 + t: here u + g = y1 + t and v + g = y + t. Its cells have colors X = 1, 1, and c(x, y+t). So **c(x, y+t) = 0**.

The orders x < y2 and x < y2 + t hold because y2 > x.

Part 2. Put g' = z1 - x. Then g' = y + t - z2, because z1 + z2 = x + y + t. The pairs of length g' that we use are:
- (x, z1): an AA pair, with color 0;
- (x+t, z1+t): a BB pair, with color 1;
- (z2, y+t): an AB pair, with color X'.

Since z2 - x is a difference of A, it is larger than 2t, so x + t < z2. We use two L's.
- The L with u = x + t < v = z2: here u + g' = z1 + t and v + g' = y + t. Its spanning pair (x+t, y+t) is a BB pair. So its cells have colors 1, X', 1, and X' = 0.
- The L with u = x < v = z2: here u + g' = z1 and v + g' = y + t. Its cells have colors 0, X' = 0, and c(x, y+t). So **c(x, y+t) = 1**.

The two parts contradict each other. ∎

Every point used is in U: x, y, y2, z1 and z2 are in A, and y1+t, y2+t, x+t, y+t and z1+t are in B = A+t. Every L used is of the form (u,u+g),(v,v+g),(u,v+g) with u < v, so it is an L of V(U). The proof can be checked cell by cell.

**General-TSD form (PROVED by the same argument).** The proof uses only the following memberships. So it applies to an arbitrary TSD instance U = A ⊔ B, not only to translates. Fix x < y and t > 0, and suppose:
- x, y, p, z1, z2 are in A;
- q, p + t, x + t, y + t and z1 + t are in B;
- q + p = x + y and z1 + z2 = x + y + t (here q plays the role of y1 + t and p the role of y2);
- x < p and x + t < z2.

Then no TSD coloring exists.

The mirror image (exchange A and B, and the colors 0 and 1) and the reflection x -> -x give three more gadgets. Under reflection, AB pairs become BA pairs.

**Consequence for Proposition O.** The translate pair (A, A+2) of Proposition O survives every Lemma C test. But it fails as soon as A contains a G1 configuration with t = 2: an A-pair (x, y) such that both x + y - 2 and x + y + 2 are sums of two elements of A strictly between x and y. So the translate obstruction is an obstruction only to first-generation arguments. It is not an obstruction to TSD.

**What remains for the translate family (OPEN, precise).** This is the *Counting Lemma G1(t)*. There should be eta > 0 and N_0 such that every Sidon set A ⊆ [0,N] with N >= N_0, |A| >= (1-eta) sqrt(N), and no difference in [1,2t] contains a G1 configuration of step t. A positive-density version (at least c N disjoint copies) would be needed to turn G1 into a proportional deficit for translate-correlated pairs.
- The statement is about the 3-point correlation sum_s 1[s in A+A] r_in(s-t) r_in(s+t) of the sumset. Here r_in counts representations by elements strictly inside the A-pair that realises s. It is not controlled by the pair-correlation (energy, Lemma E) estimates available here.
- *Heuristic only.* For random-like A, about a constant fraction of the ~N/2 A-pairs (x,y) with y - x ≍ N have both x+y±t in the inner sumset, each with probability about 1/16. So Θ(N) copies are expected.
- I could not prove it. I also found no structured near-maximal Sidon family that avoids it. Residue-class restrictions would avoid it, but they cost a constant factor in size.

### C4. TSD instances, first-generation forcing (Lemma C) and the translate obstruction (PROVED here, proofs included)

**Definition (TSD instance).** A TSD instance of span m is a triple (A, B, c): A and B are disjoint Sidon sets contained in one interval of m+1 consecutive integers, U = A ∪ B, and c is a coloring of the pairs x < y of U with colors {0,1} such that
- c(x,y) = 0 whenever x, y ∈ A ("A-pairs"), and c(x,y) = 1 whenever x, y ∈ B ("B-pairs");
- c is proper: for all u < v in U and g > 0 with u+g, v+g ∈ U, the three values c(u,u+g), c(v,v+g), c(u,v+g) are not all equal. (The case v = u+g is included.)

This is Lemma 0 for V(U) written in pair language: the L L(u, g, h') with h' = v+g−u has cells (u+g,u), (u+h',u), (u+h',u+h'−g), i.e. the pairs (u,u+g), (u,v+g), (v,v+g). Pairs with one end in A and the other in B are "mixed"; their colors are free.

**Link to ternary sources (from C3, Corollary U).** For a proper ternary source, a shift d, a lag l and a color f, the set U_f(l) = A_f ⊔ B_f with c = kappa, after renaming the color e' (constant on A_f-pairs) to 0 and e (constant on B_f-pairs) to 1, is a TSD instance of span m = S − l, where S = span F_d(D); it lies in [min F_d(D), max F_d(D) − l]. Here A_f = G_e^f and B_f = G_{e'}^f are the f-colored Golomb classes of the fibres F_l(S_e(d)) and F_l(S_{e'}(d)).

**Notation.** For a Sidon set A and g > 0 let α_A(g) be the start of the unique A-pair with difference g, if it exists: α_A(g), α_A(g)+g ∈ A. Δ(A) is the set of positive differences of A.

**Lemma C1 (first-generation forcing; PROVED).** Let (A,B,c) be a TSD instance.
- (AB cell) Let a ∈ A, a+g ∈ B. If α_A(g) exists and α_A(g) > a, then c(a,a+g) = 1. If α_B(g) exists and α_B(g) < a, then c(a,a+g) = 0.
- (BA cell) Let b ∈ B, b+g ∈ A. If α_B(g) exists and α_B(g) > b, then c(b,b+g) = 0. If α_A(g) exists and α_A(g) < b, then c(b,b+g) = 1.

*Proof.* AB, first claim: the L with u = a < v = α := α_A(g) has cells c(a,a+g), c(α,α+g) = 0 and c(a,α+g) = 0 (an A-pair, as a, α+g ∈ A). AB, second claim: the L with u = β := α_B(g) < v = a has cells c(β,β+g) = 1, c(a,a+g), and c(β,a+g) = 1 (a B-pair). BA, first claim: u = b < v = β: cells c(b,b+g), c(β,β+g) = 1, c(b,β+g) = 1 (a B-pair). BA, second claim: u = α < v = b: cells c(α,α+g) = 0, c(b,b+g), c(α,b+g) = 0 (an A-pair). ∎

*Completeness (PROVED).* These are all the L's in which exactly one cell is mixed and the other two cells are equal fixed colors. A mixed spanning pair (u, v+g) has short pairs (u,u+g) ∋ u and (v,v+g) ∋ v+g; they cannot both be A-pairs or both B-pairs, since u and v+g lie in different sets. If the mixed cell is a short pair, the other short pair and the spanning pair are both A-pairs or both B-pairs, which gives exactly the four cases above.

**Lemma C (no collision; PROVED).** In a TSD instance, for every g > 0 with α_A(g), α_B(g) both defined:
- if α_B(g) < α_A(g), no a ∈ A with a+g ∈ B satisfies α_B(g) < a < α_A(g);
- if α_A(g) < α_B(g), no b ∈ B with b+g ∈ A satisfies α_A(g) < b < α_B(g).

*Proof.* Lemma C1 would force both colors on one cell. ∎

A configuration violating Lemma C is called a **C-collision**. It involves 6 points: one A-pair and one B-pair of difference g and one mixed pair of difference g, in the stated order.

**Proposition O (translate obstruction; PROVED).** Let t ≥ 1 and let A be a Sidon set with no positive difference in [1, 2t]; put B = A + t. Then A ∩ B = ∅, B is Sidon, and (A,B) contains no C-collision.

*Proof.* Disjointness: t ∉ Δ(A). For g ∈ Δ(A), α_B(g) = α_A(g) + t, so α_A(g) < α_B(g) and only the BA case matters. A BA cell (b, b+g) with b = a' + t, a' ∈ A, would need α_A(g) < a'+t < α_A(g)+t, i.e. a' ∈ (α_A(g) − t, α_A(g)), so 0 < |a' − α_A(g)| < t, a difference of A in [1,2t]. ∎

Every Sidon set loses at most 2t points when all differences in [1,2t] are removed, since each difference occurs at most once. So Proposition O applies to near-maximal Sidon sets: first-generation forcing alone cannot prove NTSD below.

### C8. The target statement NTSD

**NTSD(β, m_0).** For every m ≥ m_0 there is no TSD instance (A, B, c) of span m with |A| ≥ (1−β)Q(m) and |B| ≥ (1−β)Q(m).

Equivalently: two disjoint near-maximal Sidon sets in an interval of length m never carry a TSD coloring. NTSD is a statement about two Sidon sets and a 2-coloring of their mixed pairs. It uses the interaction of two different completion classes S_e(d), S_{e'}(d) at one shift, not the capacity of a single binary source.

**Consequence (sketch; its rigorous proof is the subject of a separate query).** NTSD(β, m_0) with explicit β, m_0 implies FD(η, S_0) of item C5, with η of order β/200 and explicit S_0. Sketch: an FD-violator has three classes of size ≥ (1−3η−2ξ)c(S) (Proposition 4.6(b)). By Proposition 4.7(a)-(b), applied to each class with λ = εS and β' = β/3, and a union bound over the three classes, some lag l ≤ εS has r_{S_e(d)}(l) ≥ (1−β')v_1 for all three e. By 4.7(c) all six Golomb pieces at that lag have size ≥ Q(S−2) − β'v_1 ≥ (1−β)Q(S−l) once Q(S−l) ≥ 6/β. So U_f(l) is a TSD instance forbidden by NTSD. Only ONE forbidden configuration in ONE near-maximal pair is needed; no positive density of contradictions is required.

### C9. Computer evidence (director's checks; evidence only, for exactly the instances listed)

A DPLL solver with unit propagation decided TSD-colorability exactly: all L's of V(U) were generated, A-pairs fixed to 0, B-pairs to 1. It was validated on the known colorable instance A = {0,1,4,13,15,21}, B = {2,5,7,16,22,23} (m = 23, |A|+|B| = 12 = Q(23)+Q(22); colorable; 76 L's).
- **Near-maximal pairs were never colorable in the sample.** A = a translate of the Bose Sidon set A0 (q elements in [0, q^2−2], q prime), B = u·A0 + s mod (q^2−1) for random units u and shifts s, kept when both are Sidon in Z and disjoint: 60 pairs for each q = 7, 11, 13, 17 (m up to 287), none colorable. Pairs (A0, A0 + j(q+1) mod (q^2−1)) for q = 5, 7, 11, 13 and several j: none colorable.
- **C-collisions are abundant in non-translate near-maximal pairs.** Over 20 random Bose pairs as above, the minimum number of mixed cells forced both ways by Lemma C1 was 1, 2, 4, 8, 10 for q = 7, 11, 13, 17, 19 (typical counts of order q). Translates by j(q+1) also have collisions; Proposition O does not apply to them, since they have small differences.
- **Small translates (the Proposition O regime).** A = a Bose set with points deleted to remove all differences ≤ 2t, B = A + t, t = 1, 2, 3: zero C-collisions in every case, as Proposition O predicts. Colorable for q = 7 (most cases), q = 11 (t = 1, 2; |A| = 9 and 7 of 11) and q = 13 (one case, |A| = 10). Not colorable in every other tested case with q = 13, 17, 19, 23 (|A|/q from 0.7 to 0.95). A G1-type gadget (the general form in C7 or one of its three mirror images) was present in all non-colorable cases except two (q = 17, t = 3, |A| = 12; q = 19, t = 3, |A| = 14). So G1 alone does not explain all non-colorability. For t = 1 (|A| = 15, 18, 21 for q = 17, 19, 23) G1 copies were present (2, 36 and 46 of them).
- **Below near-maximality, colorings are common.** A greedy search that adds random points while keeping both sets Sidon and the instance colorable reaches |A|+|B| = 14, 16, 19, 23 at m = 40, 60, 100, 160. Unconstrained random greedy disjoint Sidon pairs reach 13.6, 15.8, 19.4, 23.7 on average, against Q(m)+Q(m−1) ≈ 16, 20, 24, 30. So any proof of NTSD must use near-maximality in an essential way; β cannot be large (roughly β < 0.2 at these sizes).
