Open question attempted (flagged by this run as OPEN): is the request ratio of a ternary source bounded? Precisely, decide UW(lambda) for absolute constants lambda:

  UW(lambda): for every ternary source (D, chi) and every h with F_h(D) nonempty, min_e N_e(h) <= lambda * |F_h(D)| (possibly up to an explicit lower-order boundary term).

UW(1) is already refuted (by the boundary witness quoted in the problem; it was re-checked independently: D = [0,18), h = 15, |F_15(D)| = 3, N_e = (5,5,5); the coloring is proper). A bounded local search over 8,425 proper small sources never produced min_e N_e(h)/|F_h(D)| above 5/3. So the real question is asymptotic. Either:

(A) Construct an explicit FAMILY of proper ternary sources (D_k, chi_k), with complete proofs of properness (every directed L inside V(D_k) checked by an argument, not a computer), in which min_e N_e(h)/|F_h(D_k)| -> infinity for many h (ideally for a positive proportion of h in a window [1, H_k] with H_k -> infinity, and ideally growing linearly in h, as in the regime ratio h/146 of the problem); this is the Part D (D-b) route; or
(B) prove UW(lambda) for an explicit lambda (even lambda depending on |D| or the span only through a power smaller than the regime needs would be valuable); this would be a (D-a) result, because in the regime the ratio is about h/146 and is far larger.

Useful facts you may use (prove any you rely on; they are short):
1. Parametrise every directed L inside V(D) by (u, d, h) with 1 <= d < h: cells (u+d, u) [left], (u+h, u) [corner], (u+h, u+h-d) [up], arm length h-d; it lies in V(D) exactly when u, u+d, u+h-d, u+h are all in D. The L is monochromatic of color e exactly when u in S_e(d), u+(h-d) in S_e(d), u in S_e(h). Hence chi proper iff S_e(h) ∩ R_e(h) = ∅ for all e, h; and every u in F_h(D) lies in at most two R_e(h) (a start in all three would have no admissible color for (u+h,u)).
2. Hence, for a PROPER source, sum_e |R_e(h)| <= 2|F_h(D)| holds automatically. So a (D-b) family needs only properness plus large ratio N_e(h)/|F_h(D)| for all three e; the request sets are then automatically squeezed.
3. Corner/arm language: m_{e,h}(u) = #{d in [1,h-1] : chi(u+d,u) = e = chi(u+h, u+h-d)}, i.e. agreements in color e between the row-u word d -> chi(u+d,u) and the reflected column-(u+h) word d -> chi(u+h, u+h-d), over the "arms" d with u+d, u+h-d in D. Properness says: at each corner (u+h,u) the agreement colors avoid the corner color chi(u+h,u). The ratio N_e(h)/|F_h(D)| is the average number of e-agreements per corner.
4. Counting heuristic (not a theorem): if D has density rho in its span and arm colors behaved independently, a corner would have about rho^2 h arms and about rho^2 h/9 agreements of each non-corner color, so the ratio would be about rho^2 h / 9 -> infinity. The obstruction to large ratios, if any, must therefore come from properness forcing row and column words to disagree.
5. The only known lower bound is R_4 >= 21, so explicit sources at the scale of the regime (spans ~2*10^7, classes ~4.6*10^5) cannot be expected; a family where the ratio grows without bound is what is wanted. Sparse D is allowed (D is any finite set of integers).

Ideas to try for (A): (a) lexicographic / digit constructions: D = {sum a_i M^i : a_i in A} for a small set A of digits and a large base M (so that sums u + (u+h) = (u+d) + (u+h-d) have no carries), and chi(v,u) defined from the most significant digit where u and v differ and from the pair of digits there; analyse which L's are possible (four points with p0 + p3 = p1 + p2) and check properness case by case according to the digit position where each pair first differs; (b) colorings that depend only on (u mod q, v mod q, v-u) or on a "level" function; (c) sources built from sets with many representations of each difference but with row/column words arranged to be anti-correlated. For each candidate, compute N_e(h) and |F_h(D)| exactly (by formula) and prove properness completely.

Also, for any family you construct: (i) say whether it can sit inside a proper four-colored square as a main-diagonal class D_c (that requires extending chi to the whole square with a fourth color c on the diagonal positions D_c; at least say what obstructs this or give the extension); (ii) state exactly which candidate inequalities it kills: UW(lambda) for every lambda; energy bounds sum_u m_{e,h}(u)^2 <= C(N_e(h) + N_e(h)^2/|F_h(D)|) for every C; union-growth lemmas |R_e(h)| >= f(N_e(h)/|F_h(D)|) |F_h(D)| with f -> a limit above 2/3; and which variants survive (e.g. those that use class sizes near the binary-source cap K, which your family will presumably not reach).

If you find instead that the ratio is bounded, give the complete proof. If neither, reduce the question to a strictly easier precise statement and prove the reduction. Separate proved statements from heuristics, and end with a list of the exact statements proved.
