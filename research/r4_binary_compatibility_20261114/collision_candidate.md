# A1: universal collision-energy candidate

For finite A subset Z with a proper binary coloring z of V(A), define
C_h^e={u:u,u+h in A and z(u+h,u)=e}. For t>0 let
m_t^e(u)=#{h:0<h<t, u,u+t-h in C_h^e}, R_t^e=sum_u m_t^e(u),
and E_t^e=sum_u m_t^e(u)^2.

Candidate C1: there is an absolute C such that E_t^e <= C R_t^e
for every such source, t and e. This is a candidate, not an established premise.
If true, Cauchy would give union size >= R/C; forcing places that union
inside C_t^{1-e}. Summing a suitable weighted version could constrain
binary-source fibers beyond their independent Golomb caps. The weighted
transfer and sufficiently strong demand would still need proof.

The first discriminator is an explicit reflected-Sidon family rather than a
large enumeration. It tests C1 for every fixed C via a parameterized family.
No near-extremality is assumed in C1. A refutation of C1 does not refute
versions with explicit density, scale, or near-extremality hypotheses.
