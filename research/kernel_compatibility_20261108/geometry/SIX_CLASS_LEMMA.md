# Shared subdiagonal positions give a strict joint capacity

All coordinates are integers starting at zero. The forbidden triple is
`(x,y),(x+d,y),(x+d,y+d)` for d>0. Let G(m) denote minimum **span** of an
m-mark Golomb set, and let g(p) denote maximum cardinality of a Golomb
subset of p consecutive positions; set g(p)=0 for p<=0.

## The joint packing lemma

Let B_1,...,B_q be pairwise disjoint Golomb subsets of `{0,...,p-1}`.
Then

`sum_i |B_i| <= sum_(j=0)^(q-1) g(p-j)`.

Proof: order the nonempty classes by their distinct minima `b_0<...<b_(s-1)`.
Then `b_j>=j`, and all of the j-th class lies in an interval of `p-b_j`
positions. Its cardinality is at most `g(p-b_j)<=g(p-j)`. Sum, then add
nonnegative terms for unused classes if s<q. Empty classes cause no issue.

This is a shared resource constraint. Separate cardinality bounds give
only `q*g(p)` and permit all classes to reuse the same earliest positions.
The inequality is an upper bound, with no claim of sharpness or attainability.

For q=6, assume the established external results

`G(24)>=425, G(25)>=480`.

For `380<=p<=463`, at most24 marks are possible in one class, and at most23
when p<=425. Among six disjoint classes, at most `min(6,max(0,p-425))` can have
24 marks: each such class has minimum at most `p-426`, and these minima
are distinct. Therefore

`sum_i |B_i| <= U(p):=138+min(6,max(0,p-425))`.

In particular U(426),...,U(430) are139,140,141,142,143 instead of144.
The bound also holds throughout `1<=p<=480` if replaced with `min(p,U(p))`;
only the range380..463 is used below. The upper restriction is essential:
p=481 would allow25-mark sets and is not covered by these two inputs.

The two inputs are supported by the primary
[OGR-24 completion reports](https://blogs.distributed.net/2004/11/) and
[OGR-25 completion report](https://blogs.distributed.net/2008/10/).
They assert exhaustive optimality, not just the existence of examples.
Their scope and the previously published numerical method are documented in
[`../../coupled_budget_20261108/numeric_upper/PROVENANCE.md`](../../coupled_budget_20261108/numeric_upper/PROVENANCE.md).
Those external searches are not repeated here.

## Six actual classes in a proper square

Let A_c be the positions of color c on the main diagonal, c in{0,1,2}.
For a fixed d>0, define

`B_(c,b)(d)={u: u,u+d in A_c and chi(u+d,u)=b}`, for b!=c.

There are six ordered choices(c,b). They are pairwise disjoint subsets of
`{0,...,n-d-1}`: u determines its original diagonal color c and its actual
completion color b. Moreover b cannot equal c, because that would give
the monochromatic L `(u,u),(u+d,u),(u+d,u+d)`.

Every B_(c,b)(d) is Golomb. To prove this without a counting surrogate,
fix c and set F={u:u,u+d in A_c}. Define a weak triangular coloring

`w(v,u)=chi(v+d,u)`, for u<=v in F.

Each image cell lies in the strict source generated by A_c, so it avoids
c; w uses only the other two colors. Translation of the first coordinate
preserves every directed L, so w is proper. Its diagonal color-b class is
exactly B_(c,b)(d).

In any proper binary weak triangle, a diagonal color class B is Golomb.
If distinct equal-difference pairs are `(a,a+h)` and `(a+t,a+t+h)` with
h,t>0, all their marks lie in B. Every strict cell with both endpoints
in B must take the opposite color. The three distinct strict cells

`(a+h,a), (a+t+h,a), (a+t+h,a+t)`

then form a monochromatic L of step t. This includes h=t, the overlapping
three-mark repeated-difference case. Hence repeated differences are
impossible.

Consequently, with `R_d=sum_c |{u:u,u+d in A_c}|`, the geometric reduction
and packing lemma give

`R_d=sum_(c!=b)|B_(c,b)(d)| <= sum_(j=0)^5 g(n-d-j)`.

This is the exact bridge to the three-color square. It simultaneously
counts all six actual completion classes, rather than estimating each
original diagonal color in isolation.

## A further color-incidence refinement

Let `1<=p=n-d<=480`, `k=max(0,p-425)`, and let m_c be the number of starts
`0<=u<k` for which `u,u+d` both have diagonal color c. If t_d denotes the
number of the six completion classes having24 marks, then

`t_d <= sum_(c=0)^2 min(2,m_c)`.

For a fixed c there are only two possible labels(c,b). Every24-mark
class has a distinct minimum in the first k starts; that minimum is one
of the m_c matching pairs. Hence at most both2 and m_c such classes can
occur. Summing proves the formula. Consequently

`R_d <=138+sum_c min(2,m_c)`.

This strengthens the raw minimum-position count by retaining original
diagonal colors. The m_c for adjacent d are functions of the same short
endpoint words, so maximizing each separately need not be jointly valid.
For example, with D=n-426, equality at every raw bound for k=1,...,6,
where d=D-k+1, would require every comparison between starts u in[0,k-1]
and u+d to match. These triangular comparisons force all six left marks
and all six right marks to have a single common color. But then at k=6
the refinement is at most2, contradicting equality at6. This example
assumes the two length-six endpoint intervals are disjoint, as they are
at n=463 or464. It proves the six raw capacities cannot all saturate;
it does not by itself give the weighted deficit needed to exclude463.

The corresponding complete finite endpoint-word optimization is delegated
to the separate `combinatorial_upper/` work package. Only the raw capacity U is
needed for the464 theorem below.

## Exact consequence R3<=464

Let f_c be the three diagonal indicator functions, zero outside the
square, and let w be a nonnegative integer sequence supported on at most
n consecutive positions, so all nonzero positive correlations have d<n.
Write `a_d=sum_i w_i*w_(i+d)` and `H=1_[0,n-1]*w`. The partition identity
`sum_c f_c=1_[0,n-1]` and pointwise Cauchy imply

`3 sum_c ||f_c*w||_2^2 >= ||H||_2^2`.

Expanding gives the necessary inequality

`sum_(d>0) (n-d-3*U(n-d))*a_d <= n*a_0`,

because `sum_c ||f_c*w||_2^2 = n*a_0+2 sum_(d>0)R_d*a_d`
and every a_d is nonnegative. No individual class size or balanced-color
assumption is used.

Take n=464 and `w_i=i*(86-i)` for i=1,...,85, zero otherwise.
Only1<=d<=84 contribute, so380<=n-d<=463. Exact summation gives

`sum_(d=1)^84 (464-d-3*U(464-d))*a_d -464*a_0 = 477965143 > 0`.

This contradicts the necessary inequality, and proves `R3<=464` using
the two external Golomb lower bounds. The root coordinator independently
reviews the geometric bridge. The integer certificate is reconstructed
from the polynomial weight formula by `audit_464.py`, with a second
literal-convolution expansion. Floating eigenvectors were used only to
suggest a weight shape; none are used in the theorem or checker.

The old independent six-class cap with these same weights gives a
nonpositive margin. The improved count, not a mere weight retuning, is
needed for this certificate. Numerical values and every correlation are
saved in `audit_464.json`.

## Scope and generalization

The abstract packing lemma applies to every q. The square-to-Golomb
reduction is specific to three colors, because deleting one diagonal
color leaves a binary weak source. With four square colors that source
is ternary and its diagonal classes need not be Golomb by this proof.

Disjoint Golomb rulers are an existing research subject. This note does
not claim priority for that concept or the elementary minimum-position
argument. Its contribution to the present program is the six-class
geometric coupling and its rigorous464 consequence. See the coordinator's
source comparison before making any stronger novelty statement.
